# Minimi — Design (one page)

**What it is.** A conversational agent with persistent, temporal, relational memory: it remembers what you said, what you decided, and what the world answered — with provenance for everything it claims. Demonstrated on the three hiring-challenge cases: (A) decision recall ("which CRMs did I shortlist for a 20-person sales team?"), (B) fact re-verification ("is Postgres self-hosting advice from November still right?"), (C) verbatim historical recall ("what did I ask on 3 November?") plus current-state comparison.

**Architecture in one breath.** A modular TypeScript monolith on **Neo4j as the authoritative store**; one infrastructure dependency. Facts are **reified `:Statement` nodes** carrying polarity, modality, authority (`user_asserted | model_inferred | externally_verified`), confidence, bitemporal bounds (valid time + recorded time, supersede-never-update), and mandatory `:Evidence` spans. External reality is captured as **immutable `:Observation`s** (never updated — supersession via `:SUPERSEDED_BY`) with **`:Capture`** records on every fetch, powers change detection that distinguishes *confirmed change* from *verified unchanged* from *insufficient evidence* — no answer claims "unchanged" without a current, dimension-comparable, authoritative, fresh observation. Entity resolution never merges on embedding similarity; identity changes only via remembered human authorization, reversible with planned splits. Retrieval is deterministic-router-first (date parsers, predicate whitelist) with an LLM planner confined to ambiguous semantic queries (validated structured output, no agent loop); fusion is Reciprocal Rank Fusion over vector + full-text + graph legs — both legs synchronous with commits, vector leg excluded from correctness-critical reads. Background work runs on an **in-process, Neo4j-backed job ledger** — fenced by a monotonic `claimGeneration` token checked in the same transaction as every durable output (never just at completion), so stale workers commit nothing even after reclaim. Raw conversation is never lost: Episode + outbox Job commit atomically.

**Honesty by construction.** Conflicts are surfaced, not resolved. Stale sources can't produce "verified unchanged." Dimension mismatches (monthly vs annual pricing) are refused, never differenced. Every answer cites evidence.

**How it's sliced.** Eleven vertical slices, each shippable with passing tests: memory spine (shipped) → contracts/fakes/eval harness → extraction → entity resolution → temporal core → hybrid retrieval + synthesis → research subsystem (pricing/releases/hosting via one observability engine) → reasoning flows → change monitoring → comprehensive evaluation with baselines → ops hardening.

**Key trade-offs** (see `docs/decisions/`): Neo4j over Postgres+pgvector and over a split vector DB (one transactional evidence spine; both legs synchronous); reified statements over property edges; four research verdicts over three-state "unchanged"; determinism over agent loops; evaluation from Slice 2, not after.

**Status.** Slice 1 verified: atomic ingest+outbox, verbatim tz-aware recall (`/recall?date=…&tz=…`), synchronous full-text search, fenced job ledger (race-tested: 8 workers × 24 jobs, exactly-one-winner; stale-failure/commit/promotion all fenced), unique `(sessionId, seq)`, shared driver with clean shutdown. `npm run db:up && npm run dev` → http://localhost:3000.
